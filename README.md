# SQL

Notes and notebooks from working through SQL across dialects.

## Structure
- `mysql/` — Colt Steele's SQL course, MySQL 8.4
- `mysql/dialect-notes.md` — running MySQL vs T-SQL differences

## Setup
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
Create a `.env` with `MYSQL_PW=<your password>`.
